# Berkah Induk Lautan

Company website for Berkah Induk Lautan, a full service maritime agency from Indonesia.
Built with React, Vite and Tailwind CSS.

## Development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

## Deployment

Deployed on Vercel. Every push to `main` triggers a new deployment.
